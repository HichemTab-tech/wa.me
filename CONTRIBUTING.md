# Contributing

Thanks for contributing to Tap to wa.me.

## Guidelines

- Keep changes small and focused.
- Match the existing Kotlin and Jetpack Compose style.
- Do not add tracking, ads, or unnecessary permissions.
- If you change user-facing behavior, update the README or privacy page when needed.

## Before Opening a PR

1. Build the app locally.
2. Test the changed flow on a device or emulator.
3. Keep the branch and commit history clean.

## Build

On Windows:

```powershell
.\gradlew.bat assembleDebug
```

On macOS or Linux:

```bash
./gradlew assembleDebug
```
